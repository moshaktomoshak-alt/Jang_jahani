# Jang Jahani – Telegram Bot

بات تلگرام «جنگ جهانی»: پیام خوش‌آمدگویی، دکمه‌ی باز کردن بازی (Mini App)، و راهنمای جدا با دکمه‌ی شیشه‌ای لینک کانال.

## نصب این پوشه توی ریپوی خودت

این پوشه (`telegram-bot/`) رو مستقیم داخل ریپوی `Jang_jahani` کنار پوشه‌های `src`, `resources` و... کپی/کامیت کن (یک سرویس جدا از خود بازیه، فایل‌های بازی رو دست نمی‌زنه).

## دیپلوی روی Railway (به‌عنوان یک سرویس جدید و جدا از سرویس بازی)

1. توی پروژه‌ی Railway‌ای که ریپوت بهش وصله، دکمه‌ی **+ New → GitHub Repo** رو بزن و همون ریپو `Jang_jahani` رو دوباره انتخاب کن (یک سرویس جدید ساخته میشه، جدا از سرویس فعلی بازی).
2. وارد تنظیمات سرویس جدید بشو → **Settings → Root Directory** رو بذار روی:
   ```
   telegram-bot
   ```
   این کار باعث میشه Railway فقط همین پوشه رو ببینه و Dockerfile اصلی بازی رو نادیده بگیره؛ خودش Nixpacks/Node رو تشخیص می‌ده.
3. توی **Variables** این سه مقدار رو ست کن:
   - `BOT_TOKEN` → توکنی که از BotFather گرفتی
   - `GAME_URL` → آدرس https همون سرویس بازی روی Railway (یا دامنه‌ی خودت)
   - `CHANNEL_URL` → `https://t.me/jang_jahani3D`
4. Deploy کن. لاگ باید بنویسه: `Jang Jahani telegram bot is running...`

## تست لوکال (اختیاری، قبل از دیپلوی)

```bash
cd telegram-bot
npm install
cp .env.example .env   # مقادیر واقعی رو داخلش بذار
npm run dev
```

## نکته‌ی مهم درباره‌ی دکمه‌ی Mini App

دکمه‌ی «🎮 شروع بازی» از نوع `web_app` تلگرامه که فقط با URL معتبر **https** کار می‌کنه (پس باید سرویس بازی روی Railway از قبل بالا و دارای دامنه‌ی https باشه). اگر بخوای این دکمه رسماً به‌عنوان Menu Button کنار کیبورد تلگرام هم ثبت بشه (نه فقط زیر پیام)، باید از طریق BotFather دستور `/setmenubutton` رو هم بزنی و همون `GAME_URL` رو بهش بدی — این یک تنظیم جدای از کدِ بات و توی خودِ BotFather انجام میشه.
